## Опис завдання
Цей репозиторій містить виконання Лабораторної роботи №7, яка присвячена впровадженню алгоритмів штучного інтелекту (DNN) та багатопотокової обробки відеопотоку. Основна мета — реалізація асинхронної детекції облич без втрати продуктивності основного циклу програми.

**Основні можливості програми:**
* **Асинхронна архітектура:** Детекція об'єктів винесена в окремий потік (`std::thread`), що дозволяє GUI-інтерфейсу працювати плавно, незалежно від часу інференсу нейромережі.
* **OpenCV DNN:** Інтегровано нейронну мережу **ResNet-10 SSD** для високої точності розпізнавання облич у реальному часі.
* **Thread Safety:** Безпечний обмін даними між потоками реалізовано за допомогою м'ютексів (`std::mutex`) та атомарних прапорців.
* **Оптимізація I/O:** Налаштовано передачу відео через MJPEG та оптимізовано буферизацію кадру для стабільної роботи в середовищі віртуалізації (VMware).
* **Інтерактивність:**
    * Керування AI-модулем за допомогою клавіші `F`.
    * Збереження всіх функцій Lab 6 (фільтри 0-5, малювання мишкою, регулювання яскравості).

## Структура директорії
* `include/` — заголовочні файли, включаючи новий клас `FaceDetector.hpp`.
* `src/` — реалізація логіки, файл `FaceDetector.cpp` та оновлений `main.cpp`.
* `deploy.prototxt` & `res10_*.caffemodel` — архітектура та ваги навченої моделі (завантажуються автоматично).
* `CMakeLists.txt` — конфігурація збірки з підтримкою багатопотоковості (`-pthread`).
* `preinstall.sh` — скрипт для встановлення OpenCV та завантаження моделей DNN.
* `build.sh` — скрипт для автоматичної компіляції.
* `run.sh` — скрипт для запуску додатку.

## Інструкція із запуску
Для успішного запуску в Ubuntu виконайте наступні кроки:

1. Надайте права скриптам:
   `chmod +x preinstall.sh build.sh run.sh`
2. **Крок 1:** Встановіть залежності та завантажте AI-моделі:
   `./preinstall.sh`
3. **Крок 2:** Скомпілюйте проект:
   `./build.sh`
4. **Крок 3:** Запустіть програму:
   `./run.sh`

## Керування програмою
* **Клавіша F:** Увімкнути/Вимкнути детекцію облич (AI Mode).
* **Клавіші 0-4:** Режими фільтрації зображення.
* **Клавіша 5:** Режим малювання геометричних фігур.
* **Слайдер Brightness:** Корекція яскравості.
* **ESC:** Вихід.

## Важливо щодо продуктивності
При роботі у віртуальному середовищі показник FPS може залежати від зовнішнього освітлення. При недостатньому світлі камера автоматично збільшує час витримки, що обмежує вхідний потік. Для стабільних **30 FPS** рекомендується забезпечити яскраве освітлення об'єкта зйомки.
