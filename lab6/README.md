# Лабораторна робота №6: Обробка відеопотоку за допомогою OpenCV
**Виконав:** Андрущенко Костянтин
**Група:** ФБ-44

## Опис завдання
Цей репозиторій містить виконання Лабораторної роботи №6, яка присвячена розробці модульного C++ додатка для обробки відео в реальному часі за допомогою бібліотеки `OpenCV`.

**Основні можливості програми:**
* **Модульна архітектура:** Кожен функціональний вузол (камера, обробка, інтерфейс, керування) винесений в окремий клас у файлах `.hpp` та `.cpp`.
* **Режими обробки:** Реалізовано 5 різних фільтрів, включаючи Glitch-ефект (зсув RGB каналів), фільтри Кенні та Собеля, а також інверсію кольорів.
* **Інтерактивність:**
    * Керування режимами за допомогою гарячих клавіш (0-5).
    * Регулювання яскравості зображення за допомогою графічного повзунка (Trackbar).
    * Можливість малювання геометричних фігур (прямокутників) мишкою в реальному часі.
* **Аналітика:** Вивід поточного показника FPS (кадрів за секунду) та назви активного режиму поверх відеопотоку.

## Структура директорії
* `include/` — заголовочні файли класів (`CameraProvider.hpp`, `Display.hpp`, `FrameProcessor.hpp`, `KeyProcessor.hpp`).
* `src/` — реалізація логіки додатку та головний файл `main.cpp`.
* `CMakeLists.txt` — конфігураційний файл для системи збірки CMake.
* `preinstall.sh` — скрипт для автоматичного встановлення OpenCV та необхідних інструментів компіляції.
* `build.sh` — скрипт для автоматичної компіляції проекту.
* `run.sh` — скрипт для запуску готового бінарного файлу.
* `.gitignore` — файл ігнорування тимчасових файлів та папки збірки `build/`.

## Інструкція із запуску
Програма розроблена для роботи в середовищі **Linux (Ubuntu)**. Для успішного запуску на «чистій» системі виконайте наступні кроки в терміналі:

1. Клонуйте репозиторій та перейдіть у директорію `lab6`.
2. Надайте права на виконання скриптам:
   chmod +x preinstall.sh build.sh run.sh
3. **Крок 1:** Встановіть необхідні бібліотеки:
   ./preinstall.sh
4. **Крок 2:** Скомпілюйте проект:
   ./build.sh
5. **Крок 3:** Запустіть програму:
   ./run.sh

## Керування програмою
Після запуску відкриється вікно відеопотоку. Використовуйте наступні органи керування:
* **Клавіші 0-4:** Перемикання режимів фільтрації (Normal, Invert, Canny, Glitch, Sobel).
* **Клавіша 5:** Режим малювання (затисніть ЛКМ та ведіть мишкою, щоб намалювати прямокутник).
* **Слайдер Brightness:** Регулювання рівня яскравості відео.
* **ESC:** Вихід із програми.
